# Данные графика ДТЕК на странице shutdowns

## Где лежат
Один большой inline-`<script>` (~200 КБ) без `src`, состоящий из строк вида
`DisconSchedule.<ключ> = <JSON или литерал>` — по одной на строку.
Индекс этого скрипта (сейчас №31 в `dtek_scripts.json`) **не стабилен** — искать по содержимому
(`'DisconSchedule.fact' in content`), а не по номеру. Внешний `/src/js/static/discon-schedule.js` — только рендер, данных в нём нет.

Разбор: для каждой строки `re.match(r'\s*DisconSchedule\.(\w+)\s*=\s*(.*)', line)`, значение — `json.loads(v.rstrip(';'))`.

## Ключи
- `streets` — список улиц (большой, для уведомлений не нужен).
- `fact` — **фактический график** (главное для уведомлений):
  - `fact.today` — unix-timestamp начала текущих суток (Киев, 00:00).
  - `fact.update` — строка `"ДД.ММ.ГГГГ ЧЧ:ММ"`, когда ДТЕК обновил график. Быстрый признак изменения.
  - `fact.data[<unix_ts дня>][<очередь>][<час 1..24>] = <статус>`. Дней может быть несколько (сегодня/завтра).
- `preset` — **типовой недельный график**:
  - `preset.data[<очередь>][<день недели 1..7>][<час 1..24>] = <статус>`.
  - `preset.sch_names` — `"GPV1.1" → "Черга 1.1"`; `preset.days` — названия дней (1 = понедельник).
  - `preset.time_zone[<час>] = ["00-01", "00:00", "01:00"]` — час `"1"` это 00:00–01:00.
  - `preset.time_type` — расшифровка статусов: `yes` свет есть, `no` нет, `maybe` возможно отключение,
    `first`/`second` нет первые/вторые 30 мин, `mfirst`/`msecond` возможно нет первые/вторые 30 мин.
  - `preset.updateFact` — дата обновления.
- Флаги отображения: `showTableFact`, `showTablePlan`, `currentWeekDayIndex` и т.п.

## Сравнение снимков (для уведомлений)
1. Сначала сравнить `fact.update`; если не изменился — скорее всего, график тот же.
2. Затем дифф `fact.data` по ключам (день → очередь → час), выводить только изменившиеся часы
   с человекочитаемыми названиями из `sch_names`, `time_zone`, `time_type`.
3. Сохранять предыдущий снимок только `fact` (и при желании `preset`) в отдельный JSON — не весь список скриптов.

## Подводные камни
- Ответ, заблокированный Incapsula, не содержит `DisconSchedule` — отсутствие ключа ≠ «график пуст», это неудачный запрос.
- В консоли Windows для кириллицы запускать Python с `PYTHONIOENCODING=utf-8`.
